💾 Backup & Import Data

Simpan dan pulihkan data ke/dari file

⬇️ Export / Backup

Simpan semua data ke file lokal. Gunakan ini untuk backup rutin atau memindahkan data ke komputer lain.

💡 Tips: Export JSON berisi semua data dan bisa diimpor kembali. CSV hanya untuk dibaca di Excel.
⬆️ Import / Restore

Muat ulang data dari file JSON yang sebelumnya di-export. Data yang ada akan digabungkan.

⚠️ Perhatian: Import akan menambahkan data dari file. Data yang sudah ada tidak akan terhapus, namun duplikat mungkin terjadi jika data sama sudah ada.
🗑️ Kelola Data
